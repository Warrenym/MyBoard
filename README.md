# MyBoard

A whiteboard app that let users freely manipulate their canvas, drag and drop images, make notes, and organize boards.

Main Features:
* Freeform canvas - infinite/scrollable board where items sit at absolute X/Y positions
* Create Boards and Sub-Boards (Boards within boards)
* Drag and drop images from different sources
* Make notes

Features include:
* Resizable notes, and images
* Dynamic sidebar
